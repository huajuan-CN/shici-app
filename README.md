# 拾词 · 每日英语

一个面向大学英语四级复习的响应式 PWA，把每日词单、真实语境搜索、跟读练习与默写放在同一套学习流程里。

## 启动

在 `shici-app` 目录运行一个本地静态服务器，然后打开浏览器：

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`。麦克风跟读评分需要通过 `localhost` 或 HTTPS 打开；语音识别是否可用取决于浏览器支持。

## 功能

- 4,459 个四级词汇，按 89 天、每天约 50 词组织
- 英文/中文搜索、学习状态筛选、10/20/30/50/本日数量显示
- 单词发音、例句展开、掌握标记与自动进度保存
- 按单词联网搜索 Google 新闻、英语学习文章和 Cambridge 词典
- 每日三句跟读、原速/慢速朗读、语音识别参考评分
- 可选题量的默写练习、错词重练和正确率统计
- 深浅色主题、离线缓存、桌面/移动端安装

学习记录只保存在当前浏览器的 `localStorage` 中，不会上传到服务器。
